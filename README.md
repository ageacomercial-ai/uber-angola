# Uber Angola

Plataforma de transporte partilhado para Angola.

## Estrutura

```
uber-angola/
├── app.py              # App principal (passageiro, motorista, admin)
├── requirements.txt    # Dependências
├── .streamlit/
│   └── config.toml     # Configuração do tema
└── README.md
```

## Como rodar

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy

1. GitHub repo
2. [share.streamlit.io](https://share.streamlit.io)
3. Arquivo: `app.py`
